Standing pre-flight — run this on every new site

The reason things get skipped is that there's no fixed list. Here it is — 10 checks, in order. A site isn't "done" until all 10 pass.

#CheckHow to verify
1Apex → www 301 (or the reverse — pick one)Fetch both, confirm one redirects
2robots.txt returns text/plain + Sitemap lineFetch it — if it returns HTML, it's broken
3sitemap.xml returns application/xml, same-domain URLs onlyFetch it — count <loc> entries
4Unknown path returns a true 404Fetch /zzz-nope-123
5Per-route canonical (self, correct host)Raw HTML, pre-JS
6Unique title ≤60 + description ≤155 per routeRaw HTML, pre-JS
7Exactly one <h1> + body content in initial HTMLCritical for SPAs — the #1 recurring defect
8OG + Twitter tags, and JSON-LD where relevantRaw HTML
9GSC: property verified (Domain type, Cloudflare DNS auto-verify)Search Console
10GSC: sitemap submitted + status SuccessSearch Console → Sitemaps
⚠ #7 is the one that keeps biting. These are client-rendered SPAs — a page can look perfect in a browser and be completely empty to Google. Always check the raw, pre-JavaScript HTML, never the rendered view.
